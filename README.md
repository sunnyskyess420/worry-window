# Worry Window (Worry Toolbox)

**Give worry a scheduled 10–15 minute window — then get back to your day.**

Worry wants your whole day. This tool gives it a slot instead: park a worry when it shows up, keep it contained until its window, then work it through with a what-if / what-is reality check.

Live: https://sunnyskyess420.github.io/worry-window/

## How it works

1. **Park it** — when worry shows up, write it down and close the door
2. **One window** — a scheduled 10–15 minute block to open the list
3. **Work it** — a what-if / what-is check turns spirals into specifics

## Built with

Plain HTML/CSS/JavaScript — no build step. Hosted on GitHub Pages; open `index.html` locally or visit the live link above.
